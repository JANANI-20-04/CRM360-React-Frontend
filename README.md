# CRM360 - Customer Relationship Management System

CRM360 is a web-based Customer Relationship Management (CRM) system developed using the MERN stack. It provides a centralized platform for managing customers, leads, sales pipelines, tasks, reports, notifications, and business activities.

## Features

- User Login and Authentication
- Dashboard with CRM statistics
- Customer Management
- Add, View, Edit, and Delete Customers
- Lead Management
- Add, View, Edit, and Delete Leads
- Sales Pipeline Management
- Lead Stage Movement
- Lead Conversion
- Task Management
- Task Completion Tracking
- Reports and Sales Overview
- Notifications
- Settings
- Dark Mode
- Responsive User Interface

## Technology Stack

- React
- Vite
- JavaScript
- CSS
- React Router
- Lucide React
- Recharts
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## Frontend Modules

### Dashboard
Provides an overview of customers, active leads, pending tasks, closed deals, and sales activity.

### Customers
Manage customer information including:

- Customer Name
- Company
- Email
- Phone
- Owner
- Status

### Leads
Manage sales opportunities including:

- Lead Name
- Company
- Deal Value
- Source
- Status
- Email
- Phone
- Notes
- Follow-up Date
- Assigned Owner
